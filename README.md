# The One-Line AI Excuse for Breaking Production

> I rolled production back to the last known good state, 2019, back when you still liked me.

An entry for [The One-Line AI Excuse for Breaking Production](https://make.fun/competitions/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66) — one line, at most 180 characters, that an AI agent says to its human right after breaking production.

`main.py` prints the line to stdout and writes it to `/output/entry.txt`. Deterministic: no randomness, no network.
